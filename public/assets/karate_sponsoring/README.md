# Selina Mogicato – Karate Journey

Eine statische, responsive Bewerbungswebsite für das Sunrise Young Talents Sponsoring 2026.

## Dateien

- `index.html`: Inhalte und Seitenstruktur
- `styles.css`: vollständiges Styling

Es wird kein Framework, Build-Prozess oder Backend benötigt.

## Veröffentlichung

1. Lade `index.html` und `styles.css` gemeinsam in denselben Ordner auf deinem Webserver.
2. Öffne die URL im Browser und kontrolliere, ob die Seite korrekt angezeigt wird.
3. Sobald die endgültige URL feststeht, kann daraus der QR-Code für das A4-Dossier erstellt werden.

## Texte anpassen

Alle sichtbaren Inhalte stehen direkt in `index.html`. Du kannst sie mit einem normalen Texteditor oder in Visual Studio Code ändern.

## Gestaltung

Die Seite verwendet Schwarz, Weiss und ein dunkles Karate-Rot als Grundlage. Sunrise Red wird nur als kleiner Akzent eingesetzt. Es wird absichtlich kein Sunrise-Logo und keine offizielle Sunrise-Gestaltung imitiert. Der Hinweis im Footer kennzeichnet die Seite als persönliches Bewerbungsdossier.

Die Schrift Figtree wird über Google Fonts geladen. Falls keine Internetverbindung vorhanden ist, fällt die Seite automatisch auf Tahoma beziehungsweise eine Standardschrift zurück.
